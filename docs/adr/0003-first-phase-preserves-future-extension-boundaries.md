# 首期保留后续能力的扩展边界

最终目标是需求与设计文档描述的持续情报生产线，包括复杂样本分层逆向、跨工具验证、受控动态分析、知识积累以及报告、IOC、TTP、检测规则和沙箱签名输出。首期因时间约束只启用完整静态分析能力，用于验证技术与架构可行性；工具、Artifact、证据、验证、分析模块、报告模块、人工Gate和知识发布的契约必须允许后续以新增能力的方式接入，不能要求推翻分析主链路或迁移既有案件。预留扩展点不等于交付未来能力：动态执行、自动知识晋升和外部规则发布在对应阶段启用前必须保持明确禁用。

## Consequences

核心对象和状态需要版本化，模块通过稳定契约和能力注册接入，工作流允许增加新节点与权限。禁止用不可执行的空壳模块伪装已交付能力，也不为无法说明的未来需求提前建立复杂抽象；每个扩展点都必须对应已知的后续场景并可通过契约测试验证。
