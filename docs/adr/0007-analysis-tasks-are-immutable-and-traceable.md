# Analysis Task输入不可变且全链路可追溯

Case作为持续调查容器允许增加样本和背景，但每个Analysis Task在启动时冻结四通道输入、策略、工具与知识版本；新增信息通过同一Case中的新Task处理，不覆盖旧任务。输入、Artifact、ToolRun、Evidence、Claim、Relation、报告、人工决定和发布结果必须保留稳定引用，形成不可中断的追溯链。

## Consequences

新Task可以按哈希复用旧产物和工具结果，但必须显式引用来源并重新评估受新增输入影响的结论。任何证据失效或人工推翻都需要沿依赖关系标记下游结论、报告和知识为过期或降级，禁止只修改最终文字而保留错误状态。

一期界面和机器分析包都必须暴露这条追溯链；用户能够从报告中的高价值结论点击到Claim、Evidence、工具原始输出及Artifact内的精确证据锚点。普通过渡文字无需逐句引用，但不得承载没有Claim支持的新事实。
