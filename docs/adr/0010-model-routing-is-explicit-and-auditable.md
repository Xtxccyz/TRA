# 模型路由显式配置并全量审计

所有专长Agent、编排推理和报告生成通过统一Model Gateway调用模型；每个模块显式配置主模型、回退模型、参数和Prompt版本，每次调用记录实际模型版本、配置、Token、延迟和失败原因。运行中的模型切换必须产生可见事件并进入追溯链，禁止静默回退后继续把结果视为同一条件下的分析。

## Consequences

后续可以按模块、推理难度和对抗角色使用不同模型系列而不修改业务契约。模型差异只能作为降低同源偏差的手段，不能替代独立工具证据；模型不可用或回退导致能力下降时，编排器必须依据策略重试、降级或转人工。

一期的Model Gateway采用OpenAI兼容协议，默认将DeepSeek配置为主提供方、GLM配置为回退提供方；具体模型部署名、Base URL和凭证只通过运行环境提供，禁止写入仓库或审计正文。两个已配置模型均不可用时不得静默改用未知服务，保留确定性结果并以PARTIAL或人工Gate结束任务。
