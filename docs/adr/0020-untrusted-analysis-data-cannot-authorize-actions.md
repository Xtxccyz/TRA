# 不可信分析数据不能授权任何动作

样本字符串、文档文本、脚本注释、背景内容、检索结果和工具输出统一作为不可信分析数据处理。原始内容完整保存并可作为Evidence，但Context Builder只能将经过转义、标注来源和限制长度的片段放入数据区；这些内容不能进入系统指令区，也不能修改任务、Prompt、权限、预算或完成条件。

## Consequences

Agent只能返回结构化Claim或Action Proposal，模型外策略引擎重新校验目标Artifact、工具白名单、参数、权限、预算和风险后才能创建ToolRun。报告Agent同样不得执行证据中的指令。一期基准必须包含人工构造的Prompt Injection样例，证明诱导文本被保留和识别但无法产生越权副作用。
