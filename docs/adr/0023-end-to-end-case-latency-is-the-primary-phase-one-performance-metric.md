# 一期性能首要衡量单Case端到端时延

一期以固定硬件、模型、工具版本和基准样例下B0×D3及B1×D2/D3 Case的端到端系统处理时延为首要性能指标，首批基础分诊、Artifact树和IOC可见时间作为辅助时延指标；并发吞吐、Token、CPU、内存、存储和单Case成本作为次级指标。人工Gate等待时间单独记录，不计入系统处理时延但保留总历时。

## Consequences

W4完成首个单样本闭环后先建立可复现实测基线，再冻结版本化数值门槛，不在缺少运行环境和样本复杂度数据时预设分钟数。每个模块、ToolRun、模型调用和报告模块都记录耗时；任何性能优化不得降低行为精确率、证据覆盖、隔离边界或虚假COMPLETE为零等质量要求。
