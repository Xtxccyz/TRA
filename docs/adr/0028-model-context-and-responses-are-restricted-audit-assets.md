# 模型上下文与响应作为受限审计资产完整留存

一期完整记录每次实际模型调用所使用的模型与版本、参数、Prompt版本、有序上下文清单、转换与裁剪、脱敏后的最终消息、原始响应、解析结果、Token、延迟及重试或缓存关系，以满足结论复现和全链路审计。PostgreSQL保存不可变调用元数据、来源关系、内容摘要和访问分级，完整请求与响应作为加密、内容寻址的受限审计载荷保存到MinIO/S3；它们不得进入普通运维日志、RAG或后续分析上下文。

## Consequences

平台凭证、访问Token和解压密码等控制面秘密在进入模型前即替换为不可逆占位符，因此持久化内容与模型实际接收内容一致；样本中提取出的IOC、配置值和其他分析证据不能被通用脱敏规则误删。每个载荷记录SHA-256、Schema版本、密钥标识和安全分级，并通过model_call_id连接到Claim、Audit Event与Trace。默认策略为Case归档后继续保留完整载荷180天；获授权的保留冻结可以延长正文期限。即使载荷按策略到期，其元数据、摘要、上下文来源关系和销毁Audit Event仍保留。
