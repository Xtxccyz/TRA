# 人工样例约束能力深度，不约束报告内容和输入

验收对齐人工样例（如 Resume 分析报告）所展示的恢复能力：模块 HOW、解码配置、参数与阈值、失败回退、可落地 IOC。不套用其章节、不复述其 IOC、不把该报告写入分析上下文或 few-shot。当前样本没有的行为保持 UNKNOWN，不得为凑齐样例结构而生成空章或编造结论。

现有 `benchmarks/gold/resume-*.json` 与那篇人工报告都不是完整标准答案：JSON 是 evaluator 回归下限，报告里也有待补充项和可质疑的 flags 解读。JSON 全绿不等于 Resume 深度已达标；未列入的槽位不得当成系统没有该能力。
